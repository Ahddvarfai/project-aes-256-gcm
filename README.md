# Implementasi AES-256-GCM Menggunakan Python

## Deskripsi
Project ini merupakan implementasi algoritma kriptografi simetris Advanced Encryption Standard (AES) dengan panjang kunci 256-bit dan mode operasi Galois/Counter Mode (GCM) menggunakan bahasa pemrograman Python.

Program mendemonstrasikan proses enkripsi, dekripsi, verifikasi hasil dekripsi, serta pengujian integritas data.

## Teknologi
- Python 3
- AES-256-GCM
- Cryptography Library
- Git dan GitHub

## Fitur Program
1. Membuat kunci AES-256 secara acak.
2. Membuat nonce sepanjang 12 byte.
3. Melakukan enkripsi plaintext.
4. Menampilkan ciphertext dan authentication tag.
5. Melakukan dekripsi ciphertext.
6. Memverifikasi kesamaan plaintext.
7. Menguji integritas data melalui manipulasi ciphertext.
